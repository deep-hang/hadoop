# 基础镜像构建

版本及校验值写在 Dockerfile 中，组员不得在普通功能分支自行升级。构建入口见根 README。

默认直接从 Apache Archive 下载 Hadoop。如果下载较慢，可提前将同一个官方 `hadoop-3.3.6.tar.gz` 放入 `docker/cache/`，再执行相同的 build 命令。构建时将安装包只读挂载、复制进临时目录，并执行相同的固定 SHA512 校验；缓存错误会使构建失败。缓存目录为空时仍可直接构建，不依赖组长电脑的额外操作。

安装包不提交 Git。运行时镜像只保留解压后的 Hadoop，不包含下载缓存。使用本地缓存时 Docker 需要将它传入构建上下文，首次传输会增加约 700 MB 的上下文数据。
