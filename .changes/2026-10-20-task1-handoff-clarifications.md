# 开工与联调约定补全

原因：全流程复核发现成员尚无推送权限，提交推送和上游同步缺少操作步骤；集群启动、配置接入、依赖和验收证据仍有歧义。

变更：补充邀请成员提示、提交/同步命令、PR 手动验证要求；明确 master 提交应用、模块配置文件归属、HDFS 路径及启动依赖；增加数据持久化、真实分布式运行、资源和课程验收核对。

验证：回读仓库协作者、邀请、保护和 Release 状态；实际检查镜像工具；公共契约、文档链接与补丁检查。不新增成员功能或自动测试，不邀请或联系组员。

影响：补全现有公共接口的使用约定，不改变两参数应用入口、版本、镜像或运行代码。需 2—7 号按各自模块实现并验收。

回滚：在修复分支 git revert 本次文档提交。
