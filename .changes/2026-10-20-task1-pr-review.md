# 公共分支保护与组长审核

目的：组员通过自己的功能分支提交，公共分支合并前由组长审核。

变更：新增 .github/CODEOWNERS，所有文件归 @deep-hang 审核；启用 common/phase0-bootstrap 的 PR 审核、代码所有者审核、旧批准失效，关闭强制推送和分支删除。所有者保留管理员维护权限。补充 PR 提交与审核步骤。

影响：不限制组员在自己分支编辑哪些文件；控制其改动能否合入公共分支。不改变镜像、应用接口或模块功能。

验证：公共契约、链接及补丁检查；GitHub API 回读保护配置与 CODEOWNERS 解析结果。

回滚：所有者在分支设置中调整保护要求；代码所有者文件和文档按公共变更流程回退。
