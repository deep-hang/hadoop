# 测试与实验材料分目录

原因：tests/ 原为公共脚本平铺，docs/ 没有成员材料位置，后续多人提交容易混杂。

变更：公共测试移至 tests/common/；按任务预留模块测试和 integration/ 目录。docs/modules/ 按任务预留实验材料目录；同步脚本路径、目录校验和文档。配置、应用、运行模式已有分工，保持原位置；编排文件与变更记录明确分开提交。

公共影响：dev.ps1 / dev.sh 的 verify 改用 tests/common/verify-base.sh，组员命令不变。镜像版本和应用接口不变，源码挂载提供新测试路径，无需重新下载镜像。未实现任何成员功能或模块测试。

验证：公共契约、文档链接与空白检查；PowerShell/Bash verify 及入口行为测试。详细运行结果见公共验证记录。

回滚：在修复分支 git revert 此次提交，使脚本引用和测试目录一起恢复。
