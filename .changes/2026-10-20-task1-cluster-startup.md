# 公共集群启动能力

原因：消除基础镜像无 SSH 时的集群启动缺口，验证现有镜像能支撑后续模块；记录老师接受 Docker。

改动：新增公共 hadoop-node.sh，显式初始化且保护已有数据，管理 master/worker 前台服务与退出清理；新增隔离三节点测试配置和宿主机验证脚本，补充接入说明。提交、PR、同步与审核流程继续使用 docs/contributing.md。

影响：2—4 号复用公共启动方式并交付正式配置。镜像、版本和公共端口路径契约不变，组员无需重新下载镜像；没有实现 2—7 号正式功能模块。复验需要宿主机 Python 3，普通接入仍按原 Windows/Mac 八步说明。

验证：7 项契约检查、全仓库本地文档链接、Bash 语法与基础 verify 通过。隔离项目 hadoop-base-check-9d8c922c 通过初始化保护、两 DataNode/两 NodeManager、真实 YARN 示例、重启数据保留及服务退出联动测试，自动清理成功；记录在 runtime/ 对应目录。Mac 尚未实测。

回滚：在修复分支 revert 本次提交并按审核流程合入；停止使用新增启动器和隔离测试，原 bootstrap 开发流程及已分发镜像仍可使用。
