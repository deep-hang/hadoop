# 课程要求与范围

需求来源：老师作业 TXT、小组任务分工 PDF、项目开发规则 PDF。本阶段只完成用户指定的组长 Phase 0；分工见 [目录与分工](project-files.md)。

## 已确认的部署方式

2026-10-20，组长确认老师接受 Docker 部署。采用单台电脑上的三个独立容器完成多节点实验，无需再为此确认 Docker 是否被接受。

Windows 上 Docker 的 WSL2 后端提供 Linux 环境，容器共享其内核；与每个节点各自安装一台完整 Linux 虚拟机的结构不同。课程采用已获认可的 Docker 方式即可，见 [Docker WSL2 说明](https://docs.docker.com/desktop/features/wsl/)。

## 其余课程要求

1. 老师列出的“视频 80—120 分钟、汇报 45 分钟”针对 5 人小组，需确认本组 7 人的时长要求。
2. 后续需提交两种应用演示、PPT、含字幕配音的视频；MergeFile 由 7 号先核对老师所指实例、合并顺序、去重/排序规则与输出格式；不能仅把下载拼接 HDFS 文件当作分布式 MapReduce 实验完成。

## Phase 0 验收

1. 目录、版本、路径和公共接口一致。
2. 基础镜像构建成功，下载包校验通过。
3. Java、javac、Hadoop 版本正确，Hadoop API 编译运行通过。
4. 基础入口不自动启动集群或格式化数据。

以上已在组长电脑验证，结果见 [验证记录](phase0-status.md)。各成员仍需完成本机验收；main 为正式集成分支，v0.1-bootstrap 稳定标签后续由组长确定。
