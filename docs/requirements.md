# 课程要求与范围

需求来源：老师作业 TXT、小组任务分工 PDF、项目开发规则 PDF。本阶段只完成用户指定的组长 Phase 0；分工见 [项目首页](../README.md#目录与负责人)。

## 课程验收待确认

1. 老师要求安装 Linux 虚拟机，小组方案使用 Docker；需确认是否接受，若不接受须补充虚拟机部署与展示。
2. 老师列出的“视频 80—120 分钟、汇报 45 分钟”针对 5 人小组，需确认本组 7 人的时长要求。
3. 后续需提交两种应用演示、PPT、含字幕配音的视频；MergeFile 语义由 7 号按课程要求确认。

## Phase 0 验收

1. 目录、版本、路径和公共接口一致。
2. 基础镜像构建成功，下载包校验通过。
3. Java、javac、Hadoop 版本正确，Hadoop API 编译运行通过。
4. 基础入口不自动启动集群或格式化数据。

以上已在组长电脑验证，结果见 [验证记录](phase0-status.md)。各成员仍需完成本机验收；稳定 main 与 v0.1-bootstrap 标签后续由组长确定。
