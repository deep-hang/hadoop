# 成员 5：本地网页文本实验室

这是独立新增入口。使用真实 Hadoop 3.3.6 examples WordCount，复用统一镜像和原验证脚本。原有 `manage.*`、`console.*` 接口继续使用原逻辑；只有网页调用新增的可观测运行脚本。

## 启动

先启动 Docker Desktop，确认使用 Linux 引擎。Windows PowerShell 可以从任何目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\Workspace\01_Study\bigData\hadoop\modes\standalone\web.ps1"
```

也可以双击仓库内 `modes/standalone/web.cmd`。窗口显示实际访问地址并自动打开默认浏览器。默认地址为 <http://127.0.0.1:19875/>，仅供本机使用。

Mac/Linux 或 Git Bash：

```bash
bash /path/to/hadoop/modes/standalone/web.sh
```

参数可同时传给上述包装器：

```text
--port 19876                 使用另一个端口；0 表示系统分配
--no-open                   不自动打开浏览器
--max-input-bytes 2097152    调整输入上限，默认 1048576 字节
```

端口占用会明确报错，不停止占用程序。同一个源码目录只启动一个网页服务。Python 最低 3.10，仅使用标准库；没有 npm、服务器安装或第三方包要求。

## 第一次核验

1. 在首页填入 `hello hadoop`，换行后再输入 `hello`。选择单机，点击开始运行。
2. 页面立即进入详情，按真实检查展示环境、配置、服务、输入、计算、验证和报告阶段。结果应为 `hello=2`、`hadoop=1`，总词数 3。
3. 打开环境管理。已有初始化数据时直接启动 HDFS；真正首次使用时，明确点击初始化，再启动。启动操作会等待服务就绪。
4. 返回首页选择伪分布式，用同一文本运行，查看 HDFS 输入和输出路径、1 个 Live DataNode、安全模式关闭的证据。
5. 点击双模式对照。两种模式顺序执行，两侧完整词频及输入校验值相同才通过。
6. 在历史中打开结果、重新验证、搜索词频，下载 TSV、日志或离线报告 ZIP。
7. HDFS 文件页选择输入或输出，输入运行 ID 列出文件，或选择文件预览。NameNode 链接根据实际发布端口生成。

## 输入规则

- 直接输入与上传文件互斥，切换模式保留内容。
- 一次只上传一个 TXT，支持拖放、UTF-8 BOM、中文、空文件。
- 上传后只读预览；“改为编辑文本”把内容转入文本框，“移除文件”清除上传选择。
- 已有内容被清空、替换时确认。取消文件选择不改变原输入。
- 无内容时不允许直接提交；空 TXT 可提交，产生 0 个词。
- 上传时保留原文件名作为元数据，实际作业使用安全的 `input.txt` 文件名。
- 按 Java StringTokenizer 的空白分隔，区分大小写，保留标点。中文要统计成多个词，需要自行用空白分开。网页不额外分词、统一大小写或清理正文。
- 已提交输入以副本及 SHA-256 保存。后续编辑不改变旧实验；修改后重新运行会生成新 ID。
- 不保存浏览器草稿。刷新首页会清除尚未提交的输入；已提交输入可从结果页恢复。旧入口的多文件输入继续通过原终端入口恢复。

## 看清两种运行过程

| 项目 | 单机 | 伪分布式 |
| --- | --- | --- |
| 存储 | 本地文件系统 `file:///` | 单节点 HDFS `hdfs://pseudo:9000` |
| 计算 | 本地 MapReduce | 本地 MapReduce |
| 常驻服务 | 无 | NameNode、DataNode |
| 输入准备 | 保存到本地运行目录 | 从只读快照上传 HDFS |
| 输出 | 本地运行目录下 `output` | `/project/output/member5/<id>` |
| 容错 | 本地文件 | 1 个 DataNode、副本数 1，无多节点冗余 |

网页新增运行脚本在实际命令前后产生结构化事件，完成检查或命令后才标记成功。事件带有本次随机标识，Hadoop 普通输出不被当成阶段事件。详情可以展开阶段日志，完整日志可另行下载。

Map、Shuffle、Reduce 展开内容是原理说明，没有独立采集的子阶段不标记完成。网页不提供虚构百分比、网络数据包动画或读写分界。

两种模式的计算都在本地客户端执行，没有 YARN。NameNode 管理文件与块位置，DataNode 保存数据；页面不把 NameNode 描述为作业计算节点。

## 状态、历史与取消

- 作业执行、最近验证、报告生成分开显示。报告失败时，可单独重新生成。
- 验证会访问真实本地/HDFS 输出。HDFS 已停止时不能获得新的成功验证结论，但可以查看历史报告。
- 对照保存两侧当时的证据快照，后续单独重新验证不会改写旧对照结论。
- 网页全服务同时接受一个耗时操作，忙碌时返回现有任务链接。查询已保存记录不受影响。
- 运行页每 2 秒查询状态，刷新可恢复同一任务，断线恢复不重复提交。
- 关闭浏览器后任务继续；正常结束服务会请求取消本服务的活动任务。HDFS 常驻服务不会因为作业取消或关闭网页而停止。
- 取消时先显示正在取消，核对项目与调用标签后只停止本次临时客户端。异常退出的工作进程同样检查资源归属并修正遗留运行状态。
- 初始化、停止和移除容器是独立操作；移除容器保留数据卷，不提供删除卷或重置数据按钮。外部终端操作无法被网页互斥锁完全约束，应避免同时操作相同演示环境。
- 历史默认查询保存记录；“发现旧入口作业”在 HDFS 可用时查询旧目录。旧入口缺少的阶段和时间显示未记录，只有真实验证后才登记验证结论。

## 数据与接口

原增强入口记录仍位于 `runtime/member5/console/`，网页任务、上传和日志位于 `runtime/member5/web/`。每次作业的本地实际输出仍在 `runtime/member5/standalone/<id>/output`；伪分布式使用本项目专用卷。

网页访问路径通过 `#/task/<id>`、`#/run/<mode>/<id>` 保存当前任务或结果身份。

| HTTP 接口 | 功能 |
| --- | --- |
| GET `/api/session`、`/api/active` | 本机会话、输入上限、活动任务 |
| POST `/api/inputs` | 文本或 TXT 上传，返回输入标识 |
| POST `/api/tasks` | 固定白名单任务，返回 202 |
| GET `/api/task`、`/api/log` | 持久化状态、阶段证据、最多 64 KiB 的日志增量 |
| POST `/api/cancel` | 请求取消本次任务 |
| GET `/api/history`、`/api/result` | 历史分页和运行详情 |
| GET `/api/counts` | 完整结果的搜索、排序和每页 50 条分页 |
| GET `/api/input`、`/api/download` | 恢复保存输入，下载固定类型产物 |

任务动作：`run`、`compare`、`verify`、`report`、`doctor`、`service`、`hdfs`、`web`、`discover`。修改操作需要同源会话凭证，不开放 CORS。接口不接受用户指定 shell 命令、项目名、环境变量或任意宿主机路径。

离线 ZIP 包含完整结果 TSV、JSON 记录与 HTML；解压后打开 `index.html`。离线报告沿用原报告的 5,000 条嵌入限制，搜索范围有说明；网页表格搜索覆盖完整结果。

## 测试与故障定位

```powershell
python -B tests/standalone/test_web.py
python -B tests/pseudo/check-web.py
```

第二条是真实 Docker 集成测试，创建随机项目、专用卷和随机端口，核对标签后只清理本次资源。证据保存在 `runtime/member5/tests/<project>/result.json`。

常见问题：

| 现象 | 处理 |
| --- | --- |
| Docker 检查失败 | 启动 Docker Desktop 并确认 Linux 引擎 |
| HDFS 未就绪 | 环境页检查；仅首次明确初始化，然后启动 |
| 端口占用 | 通过 `--port` 指定其他端口 |
| 文件编码错误 | 另存为 UTF-8 后上传 |
| 任务失败 | 查看失败阶段、阶段日志及完整日志；修复后用新 ID 重跑 |
| 浏览器无法连接 | 确认启动窗口仍在运行，使用窗口显示的 `127.0.0.1` 地址 |
| 页面版本未刷新 | 修改新增网页文件后刷新浏览器；Python 服务文件变更需重启服务 |
