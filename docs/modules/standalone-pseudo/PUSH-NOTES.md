## 可用于分支交接或 PR 的正文

### 完成内容

本分支实现成员 5 的两套独立运行环境：单机模式使用本地文件系统，伪分布式模式使用单节点 HDFS；两种模式均使用本地 MapReduce 和官方 examples WordCount 作业。

新增名为 **Hadoop** 的本地网页工具，支持直接输入文本或上传 TXT，选择模式后运行真实 Hadoop 作业。运行详情展示实际阶段、输入输出路径、存储挂载、配置与日志，并支持同一输入的双模式对照。

主要功能：

- 单机运行、独立验证、自定义输入和输出防覆盖。
- 伪分布式受保护初始化、NameNode/DataNode 管理、就绪检查及数据保留。
- 终端中文菜单、自动运行 ID、历史查询、重新验证和离线 HTML 报告。
- 网页环境状态、存储过程、失败原因与恢复操作。
- 限定范围内的本地/HDFS 文件浏览、文本预览和 NameNode 页面跳转。
- 完整词频搜索、分页、TSV/日志下载、离线报告 ZIP。
- 双模式共同输入校验、独立验证、完整输出比较及阶段耗时解释。
- 当前任务取消和异常恢复，仅清理归属本次调用的临时客户端。

### 复现方式

1. 拉取 `feat/standalone-pseudo` 分支，安装 Python 3.10+，启动 Docker Linux 引擎。
2. 按公共环境文档导入 `hadoop-base:v0.1`，镜像内 Java 为 `1.8.0_442`、Hadoop 为 `3.3.6`。
3. 在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\modes\standalone\web-plus.ps1
```

4. 打开 `http://127.0.0.1:19875/`，输入自定义文本并运行单机模式。
5. 首次使用伪分布式时，在环境管理中显式初始化，再启动 HDFS；已有元数据时仅启动。
6. 执行双模式对照，检查实际存储位置、共同输入、两侧独立验证及完整词频结论。

完整操作见 [成员 5 使用 README](README-MEMBER5.md)。
